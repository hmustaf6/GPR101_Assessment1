Weekly Challenges Documentation
Week 1: Galactic Resource Manager
Date: [19/02/2025]

Objective
Develop a text-based game in C++ where the user manages resources across different planets in a galaxy.

Programming Concepts Used
Object-Oriented Programming (OOP)
Data Structures (Arrays, Vectors)
File I/O (fstream)
Application of Concepts
Object-Oriented Programming: Used classes to represent planets and resources, encapsulating data and functionality within each object.
Data Structures: Arrays and vectors were utilized to store and manage multiple planets and resources efficiently.
File I/O: Implemented file reading and writing using fstream to save and load the game state.
Importance of Concepts
Object-Oriented Programming: Crucial for structuring the game into manageable components (e.g., planets, resources).
Data Structures: Arrays and vectors allowed efficient storage and access to resource data.
File I/O: Enables saving progress and resuming the game later, which is vital for user experience.

Week 2: Haunted House Text Game
Date: [19/02/2025]

Objective
Create a haunted house adventure game in C++ where players navigate through rooms and face challenges.

Programming Concepts Used
Conditional Statements (if/else)
Loops (while, for)
Randomization (rand())
Application of Concepts
Conditional Statements: Used to handle user input and decide the outcome of their actions (e.g., entering a room, encountering a ghost).
Loops: The game runs in a loop until the player either wins or loses, making it interactive.
Randomization: Random encounters and item placements were implemented using rand() for an unpredictable game experience.
Importance of Concepts
Conditional Statements: Essential for decision-making based on user input and progressing the game.
Loops: Ensures the game stays active and keeps the player engaged until an outcome is reached.
Randomization: Keeps the gameplay fresh, increasing replayability.

Week 3: Recursive Pyramid Letters
Date: [19/02/2025]

Objective
Write a C++ program that generates a pyramid of letters using recursion.

Programming Concepts Used
Recursion
String Manipulation (string class, loops)
Application of Concepts
Recursion: Created a recursive function that builds the pyramid row by row, breaking the problem into smaller subproblems.
String Manipulation: Used the string class and for loops to manage and format each line of the pyramid.
Importance of Concepts
Recursion: A useful technique for problems that have a recursive structure, like creating a pyramid pattern.
String Manipulation: Necessary for constructing and displaying the pyramid in a readable format.

Week 4: Maze Loader
Date: [19/02/2025]

Objective
Create a C++ program that loads a maze and allows the player to navigate through it.

Programming Concepts Used
Arrays (2D arrays)
User Input (cin)
Pathfinding Algorithms (simple checking of valid moves)
Application of Concepts
Arrays: Represented the maze as a 2D array, where each element holds a value indicating a wall or open space.
User Input: Used cin to capture user input for navigation commands (e.g., up, down, left, right).
Pathfinding Algorithms: Implemented basic logic to check for valid moves, ensuring the player can navigate through the maze.
Importance of Concepts
Arrays: A 2D array is the natural choice for representing a grid-based structure like a maze.
User Input: Essential for interactive gameplay, allowing the player to influence the game state.
Pathfinding Algorithms: Ensures the game logic works by validating movement and avoiding walls.
